# Quay 登录 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 未登录不能使用 Quay 的功能页和受保护接口；单账号通过 HttpOnly 签名 Cookie 保持登录。

**Architecture:** `internal/auth` 负责账号、Cookie 签发校验、登录接口和 Gin 中间件。`cmd/server` 把中间件挂到 `/api`，并在 WebSocket 升级前做同样的校验。Vue 用 `/login`、路由守卫和 `fetch` 包装处理 401。

**Tech Stack:** Go 1.23、Gin、Vue 3、Vue Router、Vite。

## Global Constraints

- 未设置 `QUAY_USER` 时用户名是 `admin`；未设置 `QUAY_PASSWORD` 时密码是 `admin`；两个变量各自回退。
- 未设置 `QUAY_SESSION_SECRET` 时启动随机生成 32 字节密钥，重启后旧 Cookie 失效。
- Cookie 名 `quay_session`，`HttpOnly`，`Path=/`，`SameSite=Lax`，仅 `Request.TLS != nil` 时 `Secure`，不读 `X-Forwarded-Proto`。
- Cookie 值是 `base64url(过期时间的十进制秒).base64url(HMAC-SHA256)`，有效期 7 天。不携带用户名。
- 退出用同名同路径 Cookie 覆盖，`Max-Age=0`。
- 公开：静态文件、`GET /api/health`、`POST /api/login`、`POST /api/logout`。
- 其余 `/api`，以及 `/api/terminal`、`/api/vnc/ws` 升级前，必须有有效 Cookie。
- 登录失败一律 401 `{"error":"用户名或密码错误"}`。未登录一律 401 `{"error":"未登录"}`。
- 密码用 SHA-256 后再做常量时间比较，响应和日志不出现密码。
- `GET /api/auth/me` 已登录返回 `{"username":"..."}`。
